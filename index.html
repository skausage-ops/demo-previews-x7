Install on the tablet

  1. Open each app above in Chrome.
  2. Tap ⋮ → Add to Home screen → Install. Repeat for each app.
  3. Launch from the home screen — it opens full screen with no browser bar, and works offline after the first open.
Incidents filed on the QUIP tablet app show up in QA Admin on the same device. Reset from either app's menu.
